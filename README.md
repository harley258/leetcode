## 顺序（按《代码随想录》）

数组/二分/双指针 → 链表 → 哈希 → 栈与队列 → 二叉树 → 回溯 → 贪心 → 动态规划。

## 每题三件套（一步都不能省）

1. 先独立想 45 分钟（简单题 15–20 分钟），想不出再往下
2. 看题解，重点理解**"为什么这么想"**，而不是记住代码
3. **关掉题解，从零重写**（这一步是全部价值所在）
4. 第 2 天、第 7 天各重做一次
5. 错题本每题 3 行：题号 / 卡点 / 套路 → 记入 [`error-log.md`](error-log.md)

## 时长参考

简单题 15–25 min；中等题 40–60 min。**3 h/周 ≈ 每周 4–6 题**，100 题约需 18–20 周。
